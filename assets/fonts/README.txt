LOCAL FONT SETUP

Put these 8 files in this folder:

Inter_18pt-Regular.ttf
Inter_18pt-Medium.ttf
Inter_18pt-SemiBold.ttf
Inter_18pt-Bold.ttf
Inter_24pt-Regular.ttf
Inter_24pt-Medium.ttf
Inter_24pt-SemiBold.ttf
Inter_24pt-Bold.ttf

The website loads them from assets/css/fonts.css.
No Google Fonts CDN is required.

Typography:
- Normal site text: Inter 18pt
- Large headings: Inter 24pt
- Small labels/buttons: system monospace fallback
